# PulseChain

This repository collects projects that support exploration and foundational
tooling for the PulseChain chain. PumpTires is the first project in the workspace.

## Projects

### PumpTires (`pumptires/`)

A PulseChain pending-transaction monitor for the PumpTires factory. It observes
pending token creation calls, predicts deployed token addresses, and includes
event, persistence, and trading components. This work provides a starting point
for PulseChain chain integration and future projects.

See [the PumpTires README](pumptires/README.md) for project setup and operation.
